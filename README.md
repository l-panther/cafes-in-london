# Cafés in London Website

## Description
This project is a static website that showcases selected cafés in London. It provides users with key information such as location, categories, and reviews, along with an interactive map for easy navigation.

## Features
- Interactive map displaying café locations  
- Café listings with details and descriptions  
- Star ratings and review counts  
- Responsive and user-friendly interface  

## Installation
No installation is required.

## Usage
To view the website:

1. Upload all project files to a web server and navigate to the root directory, **or**  
2. Open the `index.html` file in a web browser  

## Configuration
No configuration is required. Café data can be updated directly within the source files.
